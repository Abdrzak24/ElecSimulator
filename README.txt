ElecSimulator - offline electrical simulator
1) Upload this whole folder to any HTTPS static host (Netlify Drop, GitHub Pages, Cloudflare Pages).
2) Open the link once while online. It then works fully offline.
3) iPhone: Safari > Share > Add to Home Screen.  Laptop: Chrome/Edge > Install icon in the address bar.
To update: edit index.html and change CACHE='elecsim-v9' to 'elecsim-v10' in sw.js.
